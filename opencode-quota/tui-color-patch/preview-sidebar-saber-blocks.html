Sidebar quota section — panel-faithful saber blocks

Same pixel code as the panel preview (preview-saber-panel.html), same 2.25× speed, rendered the way the sidebar would draw it: each window becomes a pixel block (quadrant glyphs, 2×2 px per cell) instead of a 1-row bar. Blade length = your live quota. The panel's empty canvas margin is trimmed so the block stays compact — the saber itself is at panel scale.

Two sizes are shown — 8 text rows per window and 6 text rows per window. The panel's saber is ~13 px thick on a 40 px canvas; these keep that same proportion at sidebar scale.

If this is the direction: I implement it in the sidebar (static cells built once per data refresh, only the blade animates per tick — performance is fine), with the usual test suite. Pick a size — or say taller (the block size is a constant; 8, 10, 12 rows are all on the table). One tradeoff to know: this makes the Quota section about 25–30 rows tall, since each window becomes a block instead of a line.
