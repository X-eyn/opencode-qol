Pixel-Level Preview — sub-cell rendering

Each terminal cell here is a true 2×2 pixel block (the rendering your terminal will do with quadrant glyphs + fg/bg colors). A 21-cell bar becomes an 84-pixel canvas: sub-cell particles, half-pixel edges, motion that steps in quarter-cells instead of whole cells.
Rendered at 120 ms (real TUI clock). Use Slow-mo 0.25× to inspect the smoothness, and Grid to see the sub-pixels. The impressive set stays as-is — this page is about the resolution upgrade technique.

◈Glyph check (your browser font)

In the real TUI these characters + two colors per cell draw the pixel blocks. Your terminal font must contain them (most monospace fonts do — same Unicode block as █▓▒░).
42×2 = 84 pixels per bar. Per cell, the two colors are fg + bg; the quadrant glyph selects which of the four sub-pixels get which. That is the full extent of what a terminal can do — and it is 4× more resolution than the current 21-cell rendering.
